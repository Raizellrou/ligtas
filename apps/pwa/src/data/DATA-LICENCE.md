# Licence of the map data in this directory

`nangka-map.json`, `nangka-graph.json` and `nangka-routes.json` are derived from
**OpenStreetMap** data for Nangka, Marikina City (OSM relation 371370), snapshot taken
2026-09-21 by `../../scripts/build-barangay-map.mjs`.

**© OpenStreetMap contributors.** OpenStreetMap data is available under the
[Open Database Licence (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/). See
<https://www.openstreetmap.org/copyright>.

## What that means here

- These three files contain OpenStreetMap data (roads, waterways, the barangay outline, the
  names and places of evacuation centers) in a reshaped form, so treat **these files** as
  ODbL-licensed. Anyone reusing them must credit OpenStreetMap contributors, and a database
  derived from them must be offered under the same licence.
- The **rest of this repository is MIT** (see the root `LICENSE`). The ODbL applies to the data
  files, not to the application code that reads them.
- The app shows the attribution on the map itself (`src/views/EvacuationMap.tsx`), and the
  root `README.md` states it.

## What is not OpenStreetMap data

The 12 purok positions are generated by the build script (OpenStreetMap has no purok
boundaries) and the flood tiers are a demo model computed from closeness to mapped waterways.
Neither is surveyed or official; see `apps/pwa/README.md`, "Evacuation map and routing".

This note records how the data is sourced. It is not legal advice; if the licensing of the data
files inside an MIT repository matters for a submission or a deployment, have it reviewed.
